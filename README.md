# Домашнее задание №4 — Notification Platform

В комплекте два документа:

- **requirements_1-7.md** — требования и архитектурное мышление (пункты 1–7).
- **rfc_8-10.md** — RFC по подсистеме гарантированной доставки (пункты 8-10).

Папка **diagrams/** содержит шесть диаграмм: по одной C4 Container и две Sequence Diagram (успешная доставка и failover) для каждого из двух вариантов. Для каждой диаграммы есть изображение **.svg** и редактируемый исходный код **.puml** (PlantUML).
